# AI For Web Developers Workshop

> See [archived](https://github.com/royderks/ai-web-workshop/tree/archived) for the old workshop materials 

AI agents are transforming how we create applications, making them smarter and more responsive to users. 

In this workshop, we’ll dive into different approaches to building AI-powered agents, from React agents to multi-agent systems. 

You’ll explore tools ranging from low-code options to frameworks like LangGraph. Through hands-on exercises, you’ll learn to compare these frameworks, design agents, and build custom tools to connect them to your own data sources. 

Whether you’re a beginner or experienced developer, this workshop will equip you with the skills to bring AI agents into your projects. 

Content: AI Agents, Tool Calling. 

Libraries: Next.js, LangChain + LangGraph.
